# Collaboration

This open-source software is a collaborative effort. <br>
The repository has several elements to provide necessary functions.

To participate in the development you can do the following:

- Contribute to the [GitHub Discussions](https://github.com/OpenEnergyPlatform/energy-technology-catalogs/discussions)
- Contribute to the [GitHub Issues](https://github.com/OpenEnergyPlatform/energy-technology-catalogs/issues)
- Follow the [workflow for collaborative development](https://github.com/OpenEnergyPlatform/energy-technology-catalogs/blob/production/CONTRIBUTING.md)
- Follow the [AI Covenant](https://openenergyplatform.github.io/energy-technology-catalogs/develop/development/collaboration/ai_covenant/) when using AI tools
